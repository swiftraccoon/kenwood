# kenwood-tmd750

Async Rust library for the Kenwood TM-D750: radio identity over CAT, MCP
region programming with read-back verification, and menu fields decoded and
patched per Programmable-Memory slot from a registry generated by
[`mcp-d75-extract`](../mcp-d75-extract/) out of the official MCP-D750
program's memory layout. Transports (USB CDC serial, Bluetooth SPP, mock)
come from [`kenwood-thd75`](../thd75/); nothing else is shared.

## What it does

- Proves the connected radio with `ID` (exact `TM-D750`), records `FV` and
  the `TY` type byte, and gates registry-backed writes on an accepted
  firmware list.
- Enters programming mode and transfers the address regions the official
  program transfers: global settings and the four per-slot menu blocks of
  each of the six Programmable-Memory slots. Pages move under five-byte
  headers (command, 24-bit address, length), with the radio's header echo
  verified and every page acknowledged.
- Writes only pages that a patch touches, inside the writable regions, each
  read first, patched under bit masks, written, read back, and compared. An
  interrupted write reports exactly which pages may have changed, and
  `Radio::recover` re-reads them without writing.
- Decodes and plans menu fields through the generated registry
  (`memory::menu_fields`), resolving per-slot fields as
  `base + 8192 * slot`.
- Parses and writes `.d750` files (256-byte header plus either the full
  1,929,472-byte image or the 393,216 bytes before the startup-screen area,
  the two lengths the official program accepts).

## Status

Menu-programming slice, verified against a scripted mock transport. Hardware
validation is pending: the CAT baud rate, the USB product id, the exact `FV`
format, the type-byte meaning, the programming-mode entry reply, and the
behavior of USB on programming-mode exit are recorded as findings when a
radio is on the bench. The registry is generated from the committed manifest
and must never be edited by hand:

```text
mcp-d75-extract extract --model tmd750 --assembly /path/to/mcp_d750.exe \
  --language-file /path/to/english.lng --mcp-version 1.00 --firmware 1.00 \
  --output tmd750/data/mcp_d750_menu_schema.json \
  --rust-output tmd750/src/memory/menu_fields.rs --strict-known-layout
```
